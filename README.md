# 社团资源库 v1.5

一个纯静态的社团资源管理导航页：托管在 GitHub Pages（免费），文件存储在 Koofr 云盘（免费 10GB）。

## 功能

- 密码门禁：没有密码看不到任何文件，未登录直接请求 API 会被 Koofr 拒绝（401）
- 上传 / 下载双模式：顶栏一键切换
- 上传模式：左侧目录树（懒加载真实目录）+ 右侧上传空间（选文件夹 / 新建文件夹 / 拖拽上传）
- 下载模式：文件夹卡片墙（每个子文件夹单独成框）+ 最新资料更新列表；进入文件夹后为浏览模式版式（返回主页、页头、子文件夹胶囊、资料卡片预览/下载），样式与原项目浏览模式一致
- 最近更新：下载模式主页右侧按修改时间倒序列出全库最新文件，点击直达所在文件夹
- 全局搜索：顶栏按文件名搜索，点击结果直达所在文件夹
- 上传：拖拽 / 点击多选、实时进度条、同名文件可选覆盖或重命名
- 上传目标可选：上传面板可切换目标文件夹，也可直接新建子文件夹
- 下载与预览：点击即可下载，图片与 PDF 在线预览
- 保密增强：凭据只存内存，刷新或关闭页面后必须重新登录，不残留任何内容

## 技术说明

- 纯原生 HTML/CSS/JS，无框架、无构建步骤，只有一个网页 + 一个配置文件
- 浏览器直接调用 Koofr REST API（`app.koofr.net/api/v2.1`），已实测支持跨域
- 文件列表、文件夹统计与主页数据带 30 秒内存缓存，重复进入秒开；上传或新建文件夹后自动刷新对应缓存
- 不使用 WebDAV：Koofr 的 WebDAV 端点不支持浏览器跨域直连
- 界面布局与视觉借鉴自旧项目 [xiaoxuehua20.github.io](https://github.com/xiaoxuehua20/xiaoxuehua20.github.io) 的浏览模式

## 目录结构

```

```

## 部署步骤

### 1. 准备 Koofr 云盘

1. 使用**专门用于社团的 Koofr 账号**登录 [app.koofr.net](https://app.koofr.net)。
2. 在网盘根目录（`/Koofr/`）下创建文件夹 `社团资源库`。
3. 在 `社团资源库` 内创建分类子文件夹（名字与 `config.js` 中的 `folder` 一致）：
   `01-学科资料`、`02-竞赛真题`、`03-活动照片`、`04-会议记录`、`05-其他`。
4. 生成应用密码：右上角头像 → Preferences（偏好设置）→ Password（密码）→ App passwords → Generate new password，命名如 `社团资源库`。
   - 若生成时可以选择权限，请勾选 `files.read`（浏览/下载）和 `files.edit`（上传）。
   - 生成的密码只显示一次，请记好。

### 2. 修改配置（可选）

如需调整分类、根路径或搜索框文案，编辑 `config.js` 后重新推送即可。

### 3. 部署到 GitHub Pages

1. 在 GitHub 上创建一个公开仓库，例如 `club-resource-center`（公开仓库才能免费使用 Pages）。
2. 在本地这个项目目录执行：

   ```bash
   git init
   git add .
   git commit -m "社团资源库 v1.5"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/club-resource-center.git
   git push -u origin main
   ```

3. 打开仓库 Settings → Pages → Build and deployment → Source 选 "Deploy from a branch" → Branch 选 `main` / `(root)` → Save。
4. 等 1–2 分钟后访问 `https://<你的用户名>.github.io/club-resource-center/`。

## 使用方法

1. 打开页面 → 输入社团 Koofr 邮箱和应用密码 → 进入资源库。
2. 默认进入"下载"模式：主页左侧是文件夹卡片（每个子文件夹单独成框），右侧是最新资料更新；点卡片进入文件夹，点更新条目跳到所在文件夹；文件夹内可预览 / 下载。
3. 顶栏切换到"上传"模式：左侧目录树 + 右侧上传空间；选择目标文件夹（或点"＋ 新建文件夹"先建目录），再把文件拖入上传区或点击选择；同名文件会询问覆盖 / 重命名 / 取消。
4. 搜索：顶栏输入文件名，从下拉结果点击即可跳到所在文件夹（上传模式下会将该文件夹设为上传目标）。
5. 用完点右上角"退出登录"；刷新或关闭页面也会自动清除密码，下次需重新登录。

## 保密与安全说明

- 密码门禁由 Koofr 服务端强制：没有密码，任何文件列表/下载请求都会返回 401。
- 密码只保存在页面内存中，不写入任何文件；刷新或关闭页面即清除，必须重新登录。
- **不要把应用密码写进代码、仓库或群聊**，只在线下告知社团成员。
- 传输全程 HTTPS 加密；文件在 Koofr 服务端加密存储。
- 已知风险：因为要支持上传，应用密码具备写权限，任何持有密码的人理论上都能通过 API 修改或删除文件。v1.5 页面不提供删除入口，但风险客观存在，请只把密码给可信成员。

## 机房部署与排障

- 若学校机房有上网白名单，需放行：
  - `app.koofr.net`（页面调用 API 的服务器，必须）
  - `*.github.io`（加载页面本身）
- 本地测试建议用本地服务器（直接双击打开 `index.html` 可能因浏览器策略无法请求）：

  ```bash
  python -m http.server 8000
  ```

  然后浏览器打开 `http://localhost:8000`。
- 刷新后仍显示旧内容或旧界面：浏览器缓存了旧版文件，请按 Ctrl+F5（Mac 为 Cmd+Shift+R）强制刷新；部署到 GitHub Pages 后需等 1–2 分钟再访问。
- 若报错 `mountId: invalid mountable (expected primary or UUID)`：检查 `config.js` 里的 `mountId`，主存储应填 `"primary"`，不要填 `"Koofr"`。
- 微信内置浏览器可能限制大文件上传/下载，建议用 Chrome/Edge 或手机系统浏览器打开。
- 免费版单文件大小上限请在机房实测，结果记录到本文件下方。
